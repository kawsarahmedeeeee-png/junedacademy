Used to / Used to be – Grammar Test

Used to / Used to be — বাংলা অর্থসহ ব্যাখ্যা Used to = অতীতের অভ্যাস / অবস্থা। Be used to + V-ing = বর্তমানে অভ্যস্ত। Present — Be used to + V-ing (অভ্যস্ত) Positive — Subject + am/is/are + used to + V-ing Ex- I am used to getting up early. (আমি ভোরে উঠতে অভ্যস্ত।) He is used to living in Dhaka. (সে ঢাকায় থাকতে অভ্যস্ত।) Negative — Subject + am/is/are + not + used to + V-ing Ex- I am not used to working at night. (আমি রাতে কাজ করতে অভ্যস্ত নই।) They are not used to sleeping early. (তারা তাড়াতাড়ি ঘুমাতে অভ্যস্ত নয়।) Question — Am/Is/Are + Subject + used to + V-ing? Ex- Are you used to living alone? (তুমি কি একা থাকতে অভ্যস্ত?) Is she used to cold weather? (সে কি ঠান্ডা আবহাওয়ায় অভ্যস্ত?) Past — Used to / Used to be (অতীত অভ্যাস / অবস্থা) Positive — Subject + used to + V1 Ex- I used to play cricket. (আমি ক্রিকেট খেলতাম।) She used to be a teacher. (সে আগে একজন শিক্ষক ছিল।) Negative — Subject + didn't use to + V1 Ex- I didn't use to smoke. (আমি ধূমপান করতাম না।) He didn't use to be lazy. (সে আগে অলস ছিল না।) Question — Did + Subject + use to + V1? Ex- Did you use to play cricket? (তুমি কি ক্রিকেট খেলতে?) Did she use to be a teacher? (সে কি আগে একজন শিক্ষক ছিল?)
